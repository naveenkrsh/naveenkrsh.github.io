// about

Engineer across the full stack

I'm a software engineer who likes owning things end to end — from the Vue/React front end, through FastAPI and .NET services, down to the Kubernetes, CI/CD and cloud infrastructure underneath. Over a decade of shipping, that full-stack plus DevOps combination has become my default way of working.

Right now I'm focused on autonomous GenAI agents and LLM-powered applications at Energy Exemplar, building AI capabilities into PLEXOS — the energy-market modeling and simulation platform. That means orchestrating agents, wiring up RAG and agentic workflows, and making LLM systems reliable enough for production.

A big part of that is evaluation — I build eval harnesses for AI agents, turning real production traces into regression test cases and assertion suites so agent behaviour stays correct as it evolves. Lately I'm also building a software factory: tooling that streamlines how software gets scaffolded, tested, and shipped.

I also enjoy working close to the data layer — I've contributed to open-source .NET implementations of Apache Parquet and Delta Lake, hacking on low-level encoders and storage formats.
